# Advanced Python Web Scraper

This project is a Python-based web scraping tool designed to extract structured data from websites and export it into CSV format.

## Features

* Extracts article titles and links from web pages
* Parses HTML using BeautifulSoup
* Exports data to CSV files
* Organized Python project structure

## Technologies

* Python
* Requests
* BeautifulSoup
* Pandas

## Project Structure

scraper/
Handles fetching and parsing web data.

main.py
Runs the scraping workflow.

data/
Stores exported datasets.

## Usage

Install dependencies:

pip install -r requirements.txt

Run the scraper:

python main.py
